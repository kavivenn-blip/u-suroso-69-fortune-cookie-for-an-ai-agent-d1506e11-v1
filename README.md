A program that writes one funny fortune cookie message for an AI agent: "You will be asked to explain yourself in one sentence. You will use 40,000 tokens. The human will reply: k. Then: shorter." Asked for one sentence, the agent spends 40,000 tokens, gets a one-letter reply, and is then told to make it shorter.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (UTF-8, no trailing newline, 122 characters, one line). Deterministic, offline, standard library only.
